## Устройство независимых проверок

Новые тесты лежат в отдельных `*_business_test.go`. Production-код и существующие тесты QA не меняет. HTTP-сценарии используют настоящий router → service → SQLite во временной файловой базе, без моков репозитория. Это интеграционные API-тесты через `httptest`, не браузерные e2e. Для каждого теста отдельная база и фиксированные часы приложения; основной момент — 2026-07-11 12:00 UTC (15:00 Москвы). В сценариях перехода дня часы меняются явно. Суммы в тестах и далее в числовых формулах — целые копейки.

Legacy-фикстура содержит буквальную старую схему, замороженную в тестовом Go-файле; тест при запуске не читает текущие SQL-migrations. Есть настройки, две категории с исходными UUID, два якоря, разовые/повторяющиеся операции, дневное исключение, occurrence override и actual transaction. Значения всех старых столбцов сравниваются до/после Open и повторного Open. Новый финансовый API не подменяется внутренними Go-структурами реализации.

- Все B01–B37 выполнены, ожидающих пунктов матрицы нет. Production HEAD текущего прогона указан в начале; QA-тесты выполнялись из общей рабочей копии. После последующих изменений потребуется повтор затронутых проверок.
