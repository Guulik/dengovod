## Границы версии

Калькулятор сохраняет итоговую сумму, исходная формула не сохраняется. Знаменатель — календарные дни, без производственного календаря. Вхождение подтверждается целиком, без частичных оплат.

В legacy-базе неизвестную историю изменений дневной стоимости восстановить невозможно: последнее известное значение становится исходной версией. Старые планы автоматически не превращаются в факты; после обновления показана неблокирующая сверка остатка.

Прогноз и поиск следующего дохода ограничены 3660 днями. Если ожидаемого дохода в этом окне нет, применяется конец текущего месяца. Далёкая история читается через факты, якоря и интервалы; невидимые тысячелетние промежутки не разворачиваются по дням.

Для локальных e2e использован установленный Chrome: загрузка штатного Chromium оборвалась по сети. Полный Linux-прогон использует штатный Chromium в CI. Production-сборка предупреждает о JS chunk больше 500 kB; выделение модулей остаётся последующим улучшением.
