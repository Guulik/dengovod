Документация по проектированию приложения «Денговод» — финансового календаря для ответа на вопрос:

> «Если я проживу по своему плану до следующего дохода, сколько свободных денег у меня останется?»

## Зафиксированные решения

- Мультипользовательский режим: идентификация по логину (без пароля), `user_id = UUID v4`
- Баланс через «якорь» (`BalanceAnchor`) + автоматическое списание прошедших событий и стоимости дней
- Базовая стоимость дня аддитивна к событиям; оверрайды на диапазон дат
- «Деньги на жизнь» = баланс − обязательные расходы − стоимость дней до горizonta
- Горизонт: настраиваемый (`END_OF_MONTH` по умолчанию, `NEXT_INCOME`, `CUSTOM_DATE`)
- План (`FinancialEvent`) и факт (`ActualTransaction`) — раздельные сущности
- Повторения: декларативные правила, вхождения разворачиваются на лету
